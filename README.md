# Kochia — SFPA Digital Health PWA

A bilingual (Arabic / English) Progressive Web App providing confidential sexual and reproductive health information, interactive tools, and service pricing for SFPA Sudan clients.

## URL
https://sfpa-kochia.vercel.app/

## Content notes

- All health content is bilingual (Arabic RTL / English LTR). Language is toggled at runtime; `dir` and `lang` are set on `<html>`.
- Prices in `services.js` are from the SFPA Medical Services Registry. `price: null` means the service is free.
- Clinic records in `facilities.js` are placeholders — populate with verified data before go-live.
- The app is fully offline-capable once loaded (Workbox pre-caches all JS, CSS, and HTML; Google Fonts are cached on first network fetch).

## Architecture notes

- All translatable strings live in `src/data/translations.js` — white-label by editing one file.
- Content (articles, videos, tools, FAQs) lives in `src/data/` — swap without touching components.
- Components are stateless where possible; state lives in `App.jsx`.
- RTL layout is driven by a `dir` attribute on the root element; no CSS duplication needed.

## Deploy to Vercel via GitHub

1. Push this repository to GitHub.
2. Go to [vercel.com](https://vercel.com) → New Project → import the GitHub repo.
3. Vercel auto-detects Vite. Accept the defaults (build command: `vite build`, output directory: `dist`).
4. Deploy. The `vercel.json` rewrite rule ensures client-side routing works correctly.

## Constraints (do not add)

- No login or authentication
- No analytics platform
- No backend database (Supabase, Firebase, Odoo, OpenEMR, etc.)
- No real WhatsApp / Turn.io API integration (the FAB opens a `wa.me` link only)
- No fabricated clinic coordinates, phone numbers, or prices not confirmed by SFPA

## Customisation checklist before go-live

| Item | File | Field |
|------|------|-------|
| WhatsApp number | `src/data/facilities.js` | `WA_NUMBER` |
| Facility coordinates | `src/data/facilities.js` | `FACILITIES` array |
| Organisation name | `src/data/translations.js` | `orgName` |
| PWA app name | `vite.config.js` | `manifest.name` |
| Theme colour | `vite.config.js` | `manifest.theme_color` |
| App icons | `public/icons/` | Replace `icon-192.png`, `icon-512.png` |

## Before deploying

1. **Configure contact details** — open `src/config.js` and set:
   - `WA_NUMBER` — WhatsApp number in international format, digits only (e.g. `'24912345678'`)
   - `CALL_CENTRE` — telephone number shown as the call-centre contact
   
   If either value is left empty (`''`), that contact button shows a placeholder rather than a broken link.

2. **Add clinic data** — open `src/data/facilities.js` and fill in real addresses, coordinates, phone numbers, and service lists for each clinic.

3. **Add PWA icons** — generate `public/pwa-192.png` and `public/pwa-512.png` from `public/favicon.svg` using a tool such as [Squoosh](https://squoosh.app) or [PWA Asset Generator](https://github.com/elegantapp/pwa-asset-generator). Also generate `public/apple-touch-icon.png` (180×180 px).

4. **Add videos** — open `src/data/videos.js` and add real video URLs.
